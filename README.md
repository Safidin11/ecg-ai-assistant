# ECG AI Assistant

Учебный/демонстрационный ИИ-помощник для распознавания ЭКГ по образцу PMcardio.
Пользователь загружает фото/скан бумажной ЭКГ-ленты, приложение переводит её в
цифровой сигнал и выдаёт вероятности диагнозов на основе модели, предобученной
на датасете PTB-XL.

> ⚠️ **Это не медицинское изделие.** Инструмент носит образовательный и
> исследовательский характер и не предназначен для постановки диагноза,
> назначения лечения или замены консультации врача. Подробности — в
> [PROJECT.md](PROJECT.md).

## Архитектура (кратко)

Пайплайн из 4 блоков — подробное описание в [PROJECT.md](PROJECT.md):

1. **Дигитайзер** — изображение ЭКГ → цифровой сигнал (12 отведений, N отсчётов, мВ)
2. **База данных** — хранение записей и предсказаний с версией модели
3. **Модель диагностики** — сигнал → вероятности диагнозов (на старте — предобученная на PTB-XL)
4. **Веб-интерфейс** — загрузка ЭКГ и просмотр результата

## Стек

- Backend / API: Python, FastAPI, SQLAlchemy
- БД: SQLite (на старте)
- Хранение сигналов: файлы (WFDB / npy), в БД — только путь и метаданные
- Frontend: простой HTML/JS

## Структура проекта

```
backend/app/
  api/        — роуты FastAPI
  core/       — конфигурация, общие утилиты
  db/         — подключение к БД, SQLAlchemy-модели
  models/     — доменные модели/логика
  services/   — бизнес-логика (вызов дигитайзера, модели и т.д.)
  schemas/    — Pydantic-схемы
backend/tests/
digitizer/    — код дигитайзера (заготовка)
diagnosis/    — код модели диагностики (заготовка)
frontend/     — веб-интерфейс
data/         — датасеты (в git не коммитятся)
notebooks/    — эксперименты
docs/         — документация
```

## Как запустить (backend)

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp ../.env.example ../.env   # при необходимости отредактировать
uvicorn app.main:app --reload
```

После запуска: http://127.0.0.1:8000/health

## Как открыть фронтенд-заглушку

Просто открыть `frontend/index.html` в браузере (пока без сборки).
