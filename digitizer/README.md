# Digitizer

Код дигитайзера ЭКГ (изображение → цифровой сигнал). Развивается поэтапно;
общий план и роль блока — в [PROJECT.md](../PROJECT.md), архитектура пайплайна
дигитайзера — в [docs/DIGITIZER.md](../docs/DIGITIZER.md) (если добавлен).

## Что уже есть: `ecg_layout` — распознавание раскладки по подписям

Пакет [ecg_layout/](ecg_layout/) решает первый и самый хрупкий шаг: понять,
**какое отведение где находится и какому отрезку времени соответствует**.

В отличие от Open-ECG-Digitizer и победителя PhysioNet 2024 (оба полагаются на
жёсткий шаблон раскладки), здесь мы **читаем подписи** отведений (I, II, aVR,
V1…) через OCR и восстанавливаем сетку по их положению. Это устойчивее к
нестандартным раскладкам (3×4, 6×2, 12×1) и объясняет модели, почему у 6×2
получается по 5 секунд на отведение, а не 10.

### Из чего состоит

- `leads.py` — канонические 12 отведений и их порядок в массиве `[12, N]`.
- `matching.py` — сопоставление текста OCR с отведением по **закрытому словарю**
  (12 имён). За счёт закрытого словаря ошибки OCR («VI» вместо «V1»)
  исправляются, а мусор («25mm/s», ФИО) отсеивается.
- `infer.py` — **ядро**: из координат подписей вычисляет строки/колонки, тип
  раскладки и временной отрезок каждой клетки; находит ритм-полосу.
- `ocr.py` — сменные OCR-бэкенды: `EasyOCRBackend` (реальный) и
  `FakeOCRBackend` (для тестов, без тяжёлых зависимостей).
- `detect.py` — связка `detect_layout()` + командная строка с визуализацией.

### Установка и тесты

```bash
cd digitizer
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt      # ядро + pytest (без OCR)
pytest tests/ -q                     # проверка логики раскладки
```

Тесты проверяют инференс на 3×4, 6×2 и 12×1 **без реальной картинки** —
координаты подписей подставляются синтетически.

### Прогон на реальной картинке

Нужен реальный OCR-движок (тяжёлый, тянет torch):

```bash
pip install easyocr
python -m ecg_layout.detect путь/к/экг.png --overlay out.png --json out.json
```

На выходе: тип раскладки, список отведений, таблица «отведение → строка/колонка
→ отрезок времени», картинка `out.png` с разметкой и `out.json` с картой.
